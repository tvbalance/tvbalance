# Competitive landscape (checked November 2026)

| Product | Scope | Notes |
|---|---|---|
| Homey "TV Parental Control" | LG webOS only | Daily quota; switches the TV off again if turned on while locked |
| ScreenWarden for Roku | Roku only | Windows app, local, per-app daily limits, no cloud |
| TVCP Guardian | Android TV / Google TV | Companion app on the TV, subscription for lock and app blocking |
| Sentinal | YouTube filter | Docker, Home Assistant through MQTT discovery |
| TVGuardian | Profanity filter device | Registered US trademark in the TV content-filtering field; do not use the name |

## Takeaways
- The "nobody does this" gap is closing, but nothing combines multi-brand support, Home Assistant native
  integration, channel/EPG awareness and a local-first one-time price.
- Names to avoid: anything close to TVGuardian or TVCP Guardian.
- Built-in TV parental controls exist (PIN, app locks, V-Chip) but none offer schedules plus daily budgets across brands.
