# TVBalance

**Reglas de tiempo de pantalla saludables para el televisor inteligente de tu familia.**

TVBalance es un control parental local. Aplica directamente en el televisor horarios, presupuestos de tiempo diarios y
reglas para aplicaciones, entradas y canales, y se integra de forma nativa con Home Assistant. No hay cuenta en la nube
ni telemetría.
