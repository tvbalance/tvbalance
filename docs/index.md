# TVBalance

**Healthy screen-time rules for your family's smart TV.**

TVBalance is a local-first parental control. It enforces viewing schedules, daily time budgets and
app, input and channel rules on the TV itself, and plugs natively into Home Assistant. There is no cloud account
and no telemetry.
